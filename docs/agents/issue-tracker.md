# Issue Tracker: GitHub

Issues and implementation tickets for this repository live in GitHub Issues
on `IvanLi-CN/zeroclaw`. Use the `gh` CLI for all tracker operations.

## Repository Boundary

- Tracker repository: `IvanLi-CN/zeroclaw`
- Pull request repository: `IvanLi-CN/zeroclaw`
- Default target branch: `master`
- External upstream repositories are reference-only and must not receive issue,
  branch, pull request, or settings mutations from this repository's workflows.

## Conventions

- Create issues with `gh issue create --repo IvanLi-CN/zeroclaw`.
- Read issues and comments with `gh issue view --repo IvanLi-CN/zeroclaw`.
- Express blocking relationships with GitHub issue dependencies when available;
  otherwise record `Blocked by` references in the issue body.
- Pull requests are not a triage request surface.
